# All In Streams platform

Laravel 12, Filament 5, Blade, Livewire 4, Tailwind CSS 4, and a MySQL-compatible database.

See [the workspace README](../README.md) for local setup, demo accounts, workflow rules, and integration status.

Run `composer test` for the application test suite. The Windows local runtime is managed by `scripts/Start-Local.ps1` and `scripts/Stop-Local.ps1`.

See [production deployment notes](../DEPLOYMENT.md) for the labelled sample workspace, company/agency account types, Twitch/Kick onboarding and staff-entered daily campaign reports.
